# React
Two react projects: One with a frontend and backend, the other being an overall more complex project. 

Instructions for project 1 (frontend and backend): 
1. In vscode, open project1-frontend and project1-backend in separate windows.
2. In project1-backend, open the terminal. Run the following:
npm install
npm start
3. in project1-frontend, open the terminal. Run the following:
npm install
npm run dev
4. Open the link given after running npm run dev.

For the food project:
1. in vscode, open project2 
2. in the terminal, run the following:
npm install better-sqlite3@latest --legacy-peer-deps
npm install --legacy-peer-deps
node initdb.js
mkdir -p public/images
